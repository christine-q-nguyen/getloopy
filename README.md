# getloopy

The personal site of Christine Nguyen, an AI enablement and transformation lead in Austin. Static HTML, one stylesheet, two small scripts, no build step.

## Preview locally

```sh
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

`?sketch=0` shows the crisp version of the diagrams.

## Deploy

The site lives at **https://christinenguyen.me/**. Pages link to each other with relative paths; `404.html` uses root paths so it styles correctly at any missing URL. The only address-dependent layer (canonical URL, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`) is regenerated by one command:

```sh
python3 tools/set-site-url.py https://christinenguyen.me/
```

**GitHub Pages.** `.github/workflows/pages.yml` deploys the site files (not `tools/`, this README, or the workflow) on every push to `main`. The custom domain lives in the repository's Pages settings (a `CNAME` file is ignored with a workflow deploy), the domain is verified on the account, and HTTPS is enforced.

## What's in here

```
index.html            home: selected work, open source, how I work (the nav's Work, Open Source, and Approach jump here)
work/case-*.html      one page per piece: seven selected cases and two open-source ones
about.html            about
work.html             the work on one page (hidden for now: noindex, out of the sitemap; open /work.html directly)
approach.html         how I run AI enablement in loops (hidden for now, same way)
writing.html          essays and a talk (hidden for now, same way)
research.html         the papers behind the practice (hidden for now, same way)
404.html              not found
assets/css/styles.css the design system
assets/js/site.js     reveal, copy-to-clipboard, loop traces, grid runners, play-on-view, the portrait drawing itself in
assets/js/wm-glyphs.js generated Instrument Serif outlines for a watermark trace (not loaded right now)
assets/img/           SVG glyphs, the portrait layers, and the Open Graph image
tools/set-site-url.py canonical, Open Graph, JSON-LD, sitemap, robots for a given base URL
tools/portrait.py     lifts a finished pencil portrait off its paper into the two layers About draws in
tools/og.html         the Open Graph card; screenshot it at 1200×630 to make assets/img/og.png
```
