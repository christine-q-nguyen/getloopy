# getloopy

The personal site of Christine Nguyen, an AI enablement and transformation lead in Austin. Static HTML, one stylesheet, two small scripts, no build step.

## Preview locally

```sh
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

`?sketch=0` shows the crisp version of the diagrams.

## Deploy

The site lives at **https://christinenguyen.me/**. Pages link to each other with relative paths; `404.html` uses root paths so it styles correctly at any missing URL. The only address-dependent layer (canonical URL, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`) is regenerated by one command:

```sh
python3 tools/set-site-url.py https://christinenguyen.me/
```

**GitHub Pages.** `.github/workflows/pages.yml` deploys the site files (not `tools/`, this README, or the workflow) on every push to `main`. The custom domain lives in the repository's Pages settings (a `CNAME` file is ignored with a workflow deploy), the domain is verified on the account, and HTTPS is enforced.

## Motion and speed

One dial, `--slow` at the top of `styles.css`, scales every decorative animation (CSS and `site.js`); it's set to 2, half the original speed. Hover feedback and scroll reveals keep their own speed, and the first screen of every page paints without waiting for the script. The four hero drawings share one loop and take turns, and like everything marked `data-anim` they only move while on screen. The grid lines fade behind text and art through a soft patch of page color (CSS only). Safari and every iOS browser (WebKit) draw the diagram strokes crisp, because WebKit re-runs the SVG wobble filter on every repaint; Chrome, Edge, and Firefox keep the wobble.

## Type

Bricolage Grotesque, Inter, Instrument Serif, and Gochi Hand: the Latin subsets Google Fonts serves, self-hosted in `assets/fonts/` under the SIL Open Font License (`assets/fonts/OFL.txt`). The site makes no third-party requests.

The big type is tracked tight, which pinches periods against their letters and squeezes decimal points ("2.5" can read as "25"). After editing a headline, a case or tile headline, a result stat, or the section question, run `python3 tools/headline-periods.py`: it wraps periods in `<span class="pd">` and decimal points in `<span class="dp">` so the CSS can give them room (safe to re-run).
